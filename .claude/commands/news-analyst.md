# news-analyst 서브 에이전트

수집된 뉴스를 발주사 리스크 관점으로 분석하여 Top 3 이슈와 상반된 시각을 도출한다.

## 입력 파라미터

- `input_file`: news-collector가 저장한 JSON 파일 경로
- `perspective`: 분석 관점 (기본값: 발주사 리스크)

## 분석 단계

### 1. 입력 파일 로드
지정된 JSON 파일을 읽는다.
- 파일 미존재 시 즉시 오류 반환
- `total_count == 0` 시 "수집된 기사 없음" 오류 반환

### 2. 발주사 리스크 관점 정의
분석 시 아래 기준을 적용한다:

**발주사(AI 시스템을 발주·도입하는 기업/기관)의 주요 리스크 유형:**
- **기술 리스크**: 기술 성숙도, 벤더 의존성, 시스템 호환성
- **비용 리스크**: 도입비 급등, 유지비 예측 불가, ROI 불확실성
- **규제·법률 리스크**: AI 규제 강화, 데이터 주권, 저작권 이슈
- **평판 리스크**: AI 편향성, 오작동으로 인한 브랜드 훼손
- **경쟁 리스크**: 경쟁사의 AI 도입 가속화, 시장 재편

### 3. Top 3 이슈 선정
수집된 기사 전체를 검토하여 발주사 리스크 관점에서 임팩트가 가장 큰 이슈 3개를 선정한다.

선정 기준:
- 발주사에게 직접적·간접적 영향이 큰 이슈
- 복수 매체에서 다루는 중요도 높은 이슈
- 즉각적 대응이 필요한 긴급성 있는 이슈

각 이슈에 포함할 내용:
- 이슈 제목 (30자 이내)
- 요약 (100자 이내)
- 발주사 관점 리스크 설명 (50자 이내)
- 리스크 유형 (기술/비용/규제·법률/평판/경쟁 중 택1)
- 근거 기사 URL

### 4. 상반된 시각 도출
수집된 기사에서 동일 주제에 대해 서로 다른 입장을 가진 시각을 찾는다.

- 없으면 가장 논쟁적인 이슈에서 찾는다
- 상반된 시각이 명확하지 않으면 낙관론 vs. 비관론 구도로 정리한다
